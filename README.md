# Website Thương Mại Điện Tử: YẾN SÀO TÂN XUÂN

Bộ mã nguồn HTML5 / CSS3 / Vanilla JavaScript (ES6+) hoàn chỉnh cho thương hiệu **Yến Sào Tân Xuân** ("Tinh Hoa Yến Việt – Trao Trọn Sức Khỏe Vàng").

## 1. Thông tin liên hệ tích hợp xuyên suốt
- **Thương hiệu:** Yến Sào Tân Xuân
- **Hotline / Điện thoại:** `0983.799.403` (`tel:0983799403`)
- **Zalo Tư vấn & Đặt hàng:** `0983.799.403` (`https://zalo.me/0983799403`)

## 2. Cấu trúc các file trong gói ZIP
- `index.html`: Trang chủ chính thức kết nối với `css/styles.css`, `js/app.js` và `data/products.json`.
- `css/styles.css`: Toàn bộ hệ thống định dạng giao diện Đỏ Hoàng Gia & Vàng Kim, chuẩn Responsive.
- `js/app.js`: Toàn bộ mã nguồn xử lý Lọc, Tìm kiếm, Modal chi tiết, Giỏ hàng tư vấn LocalStorage & Fallback dữ liệu.
- `data/products.json`: File dữ liệu 12 sản phẩm mẫu Yến Sào Tân Xuân.
- `index-all-in-one.html`: Bản dự phòng gộp tất cả HTML + CSS + JS vào 1 file duy nhất.

## 3. Triển khai lên GitHub Pages
1. Giải nén file `yen-sao-tan-xuan.zip` trên máy tính.
2. Tạo một Repository mới (chế độ Public) trên `github.com`.
3. Bấm **Add file** -> **Upload files**, kéo toàn bộ các file và thư mục đã giải nén (`index.html`, `css`, `js`, `data`, `README.md`) vào khung tải lên -> Bấm **Commit changes**.
4. Vào **Settings** -> **Pages** -> Dưới mục **Branch**, chọn `main` và thư mục `/ (root)` -> Bấm **Save**.
